Kenneth Borja Enhanced Portfolio

How to run:
1. Put index.html, style.css, script.js, and your main.jpg photo in the same folder.
2. Open index.html in your browser, or open the folder in VS Code/Laragon.
3. Replace CONFIG.facebookUrl in script.js with your real Facebook profile link.
4. Optional: replace the auto-generated text CV with a real PDF resume later.

Main features:
- Smooth section transitions and reveal animations
- Dark/light mode with saved preference
- GitHub project showcase using your public repositories
- Search and filter projects
- Contact form that opens an email draft
- Copy email button
- Download CV button
- Responsive mobile menu
- Scroll progress bar and back-to-top button
- Safe public contact section with general location only
